# GOAL

这是用于 skill `ocr` 的自我检查文档

# 检查 ocr 的论文是否正确

检查 `{{文件名}}.md` 文件的内容是否与 `{{文件名}}.pdf` 的字符串 `{{文件名}}` 的内容一致
- 对比两篇论文、文章的 **标题** 是否一致
- 对比两篇论文、文章的 **作者** 是否一致

- 如果**一致**，则 ocr 结果正确，则 ocr 成功
  - **关键**: 成功完成后，立即从 `to-convert.md` 中删除已完成的条目，以免重复处理
- 如果**不一致**：删除 `{{文件名}}.md`，以及 `MinerU-output` 中在上述 ocr-api 步骤产生的 `MinerU-output/{{文件夹}}` 文件夹，重新执行 ocr-api 步骤


# 检查 arXiv 论文的 ocr 的质量

如果 `{{文件名}}.md` 文件内容对应原 pdf 文件，且论文是 arXiv 论文，则进一步检查 ocr 质量。

- 确定论文的 arXiv tex source 链接 (通常 `https://arxiv.org/src/XXXX.XXXXXv3`, `https://arxiv.org/src/math/XXXXXX` 是 arXiv 论文的原始 tex source 下载链接)

- 下载 tex 文件 (需要解压缩，且里面的 `tex` 文件可能没有后缀，需要手动识别)
- 对比 `{{文件名}}.md` 文件公式与 tex 文件的公式内容是否一致。要求**仔细**检查，将 `.md` 文件按照章节分成几部分，将起始行号、起始章节标题分配给一到三个 **子智能体**。重点检查
  - 日期、作者、姓名的特殊字符
  - 箭头
  - 运算符
  - 分式结构
  - 矩阵结构
  - 公式末尾标点

  等容易在 ocr 过程中出现错误的结构
